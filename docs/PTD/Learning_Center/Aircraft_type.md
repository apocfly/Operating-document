# 航空器分类

Aircraft type



## 前言

各种航空器分类分的杂七杂八，很多人一边问：“A380-800，到底是J类还是S类”、“管制雷达上面的B类又是什么分法”。

本文将带你进行了解，通过最简单、直白的方式。



## 进近速度

由于我国是ICAO创始成员国之一。

因而，我国航行资料汇编（AIP）中统一使用ICAO标准的分类法，以下是简要记忆方法：

- A类：基本为小型单引擎飞机；
- B类：基本为小型多引擎飞机；
- C类：基本为航空公司喷气式飞机；
- D类：基本为大型喷气式飞机/军用喷气式飞机；
- E类：特种军事；

各具体机型可至：[https://skybrary.aero/aircraft-types](https://skybrary.aero/aircraft-types)，进行查询。



## DOC 8643 - Aircraft Type Designators

按照ICAO DOC 8643（此刊物无电子书籍版）有关规定，可以将飞机继续细分：

- 发动机类型
- 发动机数量
- WTC（尾流等级）

各具体机型可至：[https://www.icao.int/publications/doc-8643-aircraft-type-designators/search](https://www.icao.int/publications/doc-8643-aircraft-type-designators/search)，进行查询。

但是，也有民间制作的镜像版本：[https://doc8643.com](https://doc8643.com)，相较于官方版本，补充了没有图片的遗憾。

### 尾流等级

WTC，Wake Turbulence Category，尾流等级

在《[民用航空空中交通管理规则.中国民用航空总局.CCAR-93TM-R6](https://www.caac.gov.cn/XXGK/XXGK/MHGZ/202303/P020250811508100344431.pdf)》中的明确分为**三类**：

- 轻型机：最大允许起飞全重等于或小于7,000千克的航空器。

- 中型机：最大允许起飞全重大于7,000 千克，小于136,000千克的 航空器；

- 重型机：最大允许起飞全重等于或大于136,000千克的航空器；

前机是波音 757 型时，按照前机为重型机的尾流间隔执行。

这里的起飞全重就是最大起飞重量。

!!! Note "注意了解"

	ICAO在DOC 8643中的标准分类为：**四类**
	
	其将原本不属于上述三种分类方法的A380-800的560,000千克，单独分为了J类。

具体的尾流等级雷达及非雷达尾流间隔，可查阅：[《航空器尾流间隔》](../../CTD/Learning_Center/Wake_turbulence_separation_minima)



## RECAT-CN

RECAT-CN，Re-categorization - CN，航空器尾流重新分类

按航空器最大允许起飞全重和翼展分为**五类**：

- 超级重型机（J）：最大允许起飞全重等于或大于136,000kg，翼展等于或大于75m的航空器；

- 重型机（B）：最大允许起飞全重等于或大于136,000kg，翼展等于或大于54m、小于 75m的 航空器；

- 一般重型机（C）：最大允许起飞全重等于或大于 136,000kg，翼展小于54m的航空器；

- 中型机（M）：最大允许起飞全重大于7,000kg， 小于 136,000kg 的航空器，尾流类型标识符为 M。其中B757飞机（包含 B757-200、B757-300 等）属于中型机；

- 轻型机（L）：最大允许起飞全重等于或小于7,000kg的航空器；

具体的尾流等级雷达及非雷达尾流间隔，可查阅：[《航空器尾流间隔》](../../CTD/Learning_Center/Wake_turbulence_separation_minima)
